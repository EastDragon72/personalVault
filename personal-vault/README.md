# 개인정보 보관함 (Personal Vault)

나 혼자 사용하는 개인용 정보/비밀번호 보관 앱입니다.
서버, 회원가입, 클라우드 저장이 전혀 없으며 모든 데이터는 이 기기의 브라우저 저장소(localStorage)에만
**암호화되어** 저장됩니다.

## 실행 방법 (PC)

별도 설치나 서버 없이 바로 실행할 수 있습니다.

1. `personal-vault` 폴더 전체를 원하는 위치에 둡니다.
2. `index.html` 파일을 더블클릭해서 브라우저(Chrome/Edge 권장)로 엽니다.
3. 처음 실행하면 비밀번호 설정 화면이 나옵니다. 비밀번호를 정하면 바로 보관함이 만들어집니다.

> 참고: 브라우저 보안 정책상 `file://`로 직접 열었을 때 일부 브라우저에서 암호화 기능이 막히는
> 경우가 드물게 있습니다. 그럴 때는 폴더에서 아래처럼 아주 간단한 로컬 서버를 띄워서 열어도 됩니다.
> (인터넷 연결이 필요한 것이 아니라, 브라우저가 "로컬 서버"로 인식하게만 해주는 것입니다.)
>
> ```
> cd personal-vault
> python -m http.server 8000
> ```
> 그 후 브라우저에서 `http://localhost:8000` 접속.

## 파일 구조

```
personal-vault/
├─ index.html        화면 뼈대
├─ css/
│  └─ style.css       디자인 (흰색 배경, 단순한 스타일)
├─ js/
│  ├─ crypto.js        암호화/복호화 (PBKDF2 + AES-GCM, 표준 Web Crypto API)
│  ├─ storage.js        localStorage 읽기/쓰기 (이 기기에만 저장)
│  └─ app.js             화면 전환, 목록/입력/검색/잠금/내보내기/가져오기 로직
└─ README.md
```

## 데이터 보안

* 비밀번호는 저장되지 않습니다. PBKDF2(SHA-256, 15만회 반복)로 비밀번호에서 암호화 키를 매번 다시
  계산합니다.
* 실제 항목 데이터는 AES-GCM(256bit)으로 암호화된 상태로만 localStorage에 저장됩니다.
* 자체 암호 알고리즘을 만들지 않고, 브라우저에 내장된 표준 Web Crypto API만 사용했습니다.
* 인터넷 연결, 외부 서버 요청이 코드 어디에도 없습니다.

## 구현된 기능

* 첫 실행 시 비밀번호 설정 / 이후 실행 시 로그인
* 목록 화면 (분류 / 제목 / 내용 미리보기), 검색(분류·제목·내용 부분 일치)
* 새 항목 추가, 수정, 삭제(확인창 포함)
* 저장하지 않은 수정 내용이 있을 때 나가기 확인
* 10분 미사용 시 자동 잠금
* 내보내기: 암호화된 백업 파일(.pvb)로 다운로드
* 가져오기: 백업 파일 선택 후 비밀번호 확인 → 복원 (현재 데이터를 대체)

## 다음 단계 (Android 앱화)

지금 구조는 순수 HTML/CSS/JS(외부 프레임워크 없음)라서, 나중에 아래 방식으로 그대로
Android 앱(APK)으로 감쌀 수 있도록 만들었습니다.

* **Capacitor** 또는 **Cordova**로 이 폴더를 그대로 감싸서 WebView 기반 APK 생성
* Android에서는 localStorage 대신 안드로이드 자체 저장소를 쓰도록 `storage.js`만 교체하고,
  가능하면 **Android Keystore**로 마스터 키를 보호하도록 확장
* 화면(`index.html`, `css/`, `js/app.js`)은 거의 수정 없이 재사용 가능

원하시면 이 PC 버전을 충분히 테스트하신 뒤, Android 빌드 단계로 이어서 작업해 드리겠습니다.

## APK로 만들기 (호스팅 + PWABuilder, 코딩 지식 불필요)

이 프로젝트는 이미 앱처럼 설치 가능한 PWA(manifest.json, 아이콘, 오프라인 캐시)로 준비되어 있습니다.
아래 순서대로 하면 APK 파일을 무료로 만들 수 있습니다.

**1단계 — 무료 호스팅에 올리기 (Netlify Drop)**
1. 브라우저에서 `https://app.netlify.com/drop` 접속 (로그인 필요 없음)
2. 압축 푼 `personal-vault` 폴더를 그대로 그 페이지에 드래그 앤 드롭
3. 몇 초 뒤 `https://무작위이름.netlify.app` 같은 주소가 생깁니다. 이 주소를 복사해두세요.
   (이 주소로 폰 브라우저에서 바로 접속해서 테스트도 가능합니다)

**2단계 — PWABuilder로 APK 생성**
1. 브라우저에서 `https://www.pwabuilder.com` 접속
2. 1단계에서 받은 주소를 입력하고 "Start"
3. 잠시 분석이 끝나면 "Package For Stores" 또는 "Android" 항목 선택
4. Android 패키지 생성 → APK(또는 AAB) 파일 다운로드

**3단계 — 폰에 설치**
1. 다운로드한 APK 파일을 폰으로 옮깁니다 (카카오톡 나에게 보내기, 이메일, USB 등)
2. 폰에서 파일을 탭해서 설치 (출처를 알 수 없는 앱 설치 허용이 필요할 수 있습니다)

> 주의: 이 방식으로 만든 APK는 정식 스토어 서명이 아닌 테스트용 서명입니다. 개인적으로 설치해서
> 쓰는 용도로는 충분하지만, Play 스토어에 올리려면 별도 서명 절차가 필요합니다.
